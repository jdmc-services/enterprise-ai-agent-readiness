# AI Incident Response Playbook

## Incident Types

- Unauthorized data exposure
- Prompt injection
- Malicious retrieval source
- Incorrect automated action
- Model outage
- Excessive hallucination
- Tool misuse
- Identity compromise
- Cost or consumption anomaly

## Immediate Actions

1. Disable affected agent, connector, or tool.
2. Preserve logs and evidence.
3. Notify the incident commander.
4. Contain affected identities and credentials.
5. Revert unauthorized changes.
6. Assess data exposure.
7. Notify privacy, legal, and compliance as required.
8. Document root cause.
9. Validate corrective controls.
10. Approve controlled restoration.

## Evidence Checklist

- User identity
- Agent identity
- Prompt
- Retrieved sources
- Model response
- Tool calls
- Approval records
- System-of-record changes
- Connector logs
- SIEM events
