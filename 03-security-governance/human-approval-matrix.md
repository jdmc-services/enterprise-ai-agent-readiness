# Human Approval Matrix

| Action | Risk | Agent May Recommend | Agent May Execute | Human Approval |
|---|---|---|---|---|
| Search knowledge | Low | Yes | Yes | No |
| Draft ticket note | Low | Yes | Yes | Analyst reviews |
| Reclassify ticket | Moderate | Yes | Limited | Required |
| Reset account | Moderate | Yes | Conditional | Required |
| Modify production configuration | High | Yes | No | Change approval |
| Provide clinical guidance | Prohibited | No | No | Not permitted |
| Close critical incident | High | Yes | No | Incident commander |
