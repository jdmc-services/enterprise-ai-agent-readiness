# ROI Model

## Annual Benefit

```text
Annual Labor Savings
+ Avoided Rework
+ Reduced Overtime
+ Reduced Training Cost
+ Reduced Error Cost
+ Increased Capacity
= Gross Annual Benefit
```

## Annual Cost

```text
Platform Licensing
+ Model Consumption
+ Integration
+ Implementation
+ Security
+ Training
+ Support
+ Internal Labor
= Gross Annual Cost
```

## ROI

```text
ROI = (Gross Annual Benefit - Gross Annual Cost) / Gross Annual Cost
```

## Example

| Item | Annual Amount |
|---|---:|
| Labor savings | $240,000 |
| Overtime reduction | $80,000 |
| Reduced rework | $40,000 |
| Total benefit | $360,000 |
| Total cost | $150,000 |
| Net benefit | $210,000 |
| ROI | 140% |
