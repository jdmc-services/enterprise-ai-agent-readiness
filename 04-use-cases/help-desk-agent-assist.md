# Use Case: Help Desk Agent Assist

## Business Problem

Service-desk analysts spend excessive time searching for approved information, documenting calls, correcting ticket categories, and transferring work.

## Proposed Capability

A human-supervised AI assistant that:

- Searches approved knowledge
- Summarizes interactions
- Suggests ticket categories
- Recommends routing
- Drafts resolution notes
- Identifies repeat incidents
- Highlights missing knowledge

## Guardrails

- No autonomous ticket closure
- No privileged access without approval
- Source citations required
- Confidence threshold enforced
- Low-confidence answers escalated
- All actions logged
- Existing service-management platform remains authoritative

## Metrics

- Average handle time
- First-contact resolution
- Reassignment rate
- Abandonment
- After-call work
- Knowledge utilization
- Analyst satisfaction
- Overtime
