# Contributing

Contributions should improve the framework's usefulness for regulated, mission-critical, and enterprise environments.

## Requirements

- Use synthetic data only.
- Preserve vendor neutrality.
- Avoid employer or customer identifiers.
- Document assumptions.
- Include security and governance implications.
- Define measurable outcomes.
- Keep human oversight explicit.

## Pull Requests

Every pull request should explain:

1. The problem addressed.
2. The proposed improvement.
3. The security impact.
4. The governance impact.
5. The measurement impact.
